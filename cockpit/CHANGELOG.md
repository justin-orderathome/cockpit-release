# 更新紀錄

每一版改了什麼，新的在最上面。

## 0.10.1

- [設定] 的「套用範本」從下框線右側移進框內，自成「範本」一組，排在「更新」上面；有沒套用過的項目時一樣是高亮的「範本有 N 項新的」。

## 0.10.0

- 狀態框會告訴你「在等你」：主對話或 subagent 跳出對話框時，模型那一行下面多一行警告色的「● 等你核准：<工具內容> · 14:02 起」（問題是「等你回答」，計畫是「等你核准計畫」），回應後消失；主對話一輪結束時改成暗色的「輪到你 · 14:02 起」，你送出下一則才消失。好幾個同時在等時只寫最早的一個並加「另 N 個」；subagent 在等時，[任務] 那一列的圖示換成警告色 `?`。不發系統通知、沒有開關。
- 路線圖滑過結案的決策票，說明區直接寫結論：地圖 Decisions so far 有的寫「已定：<要點>」，Out of scope 有的寫「不做：<那一行>」，都沒有就用票的 Answer 第一段。
- 常用 prompt 可以用變數：`{{票}}` 換成主對話最近經手的票，`{{分支}}` 換成目前的 git 分支，點下去時才取。取不到時原字留在輸入框並跳 toast，結尾 ` !` 的改成只填入、不送出。
- [SKILL] 記錄叫用次數：開關模式中多一欄「N 次 · 最後 10/21」（沒用過的寫「沒用過（自 10/21 起）」），平常模式寫在說明欄標題的提示裡。紀錄是全域的，手打 `/name` 與模型叫用都算。主對話正在用的 skill，名稱前換成 `●`；subagent 正在用的寫在它那一列的說明區。
- [設定] 多了「套用範本」：作者在發布版附上整理好的常用 prompt 與 SKILL 覆寫，按一下只把你還沒有的加進自己的檔案，不改你改過的東西，寫入前備份 `.bak`。有沒套用過的項目時按鈕換成高亮的「範本有 N 項新的」。這一版附上第一份範本。
- 「等你核准」「等你核准計畫」、MCP elicitation，以及「已載入的 skill 再叫一次不計次」還沒在實機上驗過，是照引擎的型別寫的。

## 0.9.0

- [任務] 分成「路線圖／任務／背景」三個子分頁，一次看一種：按 `m`／`t`／`b` 或點分頁籤切換，打開時在「任務」，同一個 session 內切走再回來停在上次看的。分頁籤帶數字（路線圖：列出的 effort 數；任務：進度，主對話沒有任務時是 subagent 數；背景：還沒結束的數），有東西在跑加 `●`，面板窄時只留名稱。沒有內容的子分頁不顯示，只剩「任務」時和以前一樣不畫分頁籤；正在看的子分頁變空就回到「任務」。effort 全部結案時路線圖分頁籤照留、不寫數字，進去按 `d` 看已完成的。
- 新的「背景」子分頁：這個 session 丟到背景的工作都看得到，分「執行中」「排程」「已結束」三段。
  - 執行中：背景 shell 指令（`run_in_background`、Ctrl+B、逾時轉背景）、Monitor（寬度夠時寫「剩 25m」或「持續」）、Workflow，經過時間每秒走。
  - 排程：CronCreate、`/loop` 與 ScheduleWakeup 排的，依下次觸發時間排序；重複的觸發後時間往後推，說明區記「上次觸發」。
  - 已結束：完成是暗色 `✓`、失敗與被停掉（TaskStop）是紅色 `✗`，只在對話停下時發現不見的是暗色 `–`（結果不明）。只列最近 5 筆，其餘收成「▸ 更早的 N 筆」；`c` 清掉已結束的，每列的 × 單獨隱藏。
  - subagent 開的背景工作也在這裡，說明區寫是哪個 subagent 開的；subagent 還有背景工作在跑時，它在「任務」頁那一列多一個暗色「· 背景 N」。
- 自動跟隨只在「任務」子分頁裡翻頁，永遠不替你換子分頁；看路線圖或背景時不會被拉走。下框線只顯示目前子分頁的按鍵，`c` 只清目前這一頁。
- 效能：和背景工作無關的事（一般的 Read、Edit、前景指令）不多做任何事；Monitor 每輸出一行不重繪；計時由畫面那一側自己走，面板關著時零計時器。
- Workflow、ScheduleWakeup、MCP 的背景工作還沒在實機上驗過，是照引擎的型別寫的；說明區會註明。
- 其餘是內部整理（子分頁、背景工作的規則各自成為可以直接測的 module），畫面與操作不受影響。

## 0.8.5

- [任務] 看不到任務清單時會告訴你原因：主模型是 Opus／Sonnet 5.5 這類新模型時，Claude Code 預設不讓模型寫任務清單，[任務] 只看得到 subagent 列。這時標題下會多一行黃字，提示在 `~/.claude/settings.json` 的 `env` 加上 `"CLAUDE_CODE_ENABLE_TODO_TOOLS": "1"`；加了不用重開，下一次送出 prompt 後提示就消失。

## 0.8.4

- [SKILL] 看得到每個 plugin 與 skill 的版號，平常不佔版面：滑鼠停在 skill 上，說明區的標題寫著版號與更新日期（例如「v1.3.1 · 10-12」）；停在組名那一列，行尾也會浮出同樣的版號。用 `npx skills` 裝的顯示一串七碼的編號，官方 marketplace 的 plugin 顯示的也是編號；這兩種編號變了不一定代表那個 skill 有更新，看日期比較準。查不到版號的組（例如「我的 skill」）不顯示。

## 0.8.3

- [任務] 看得到帶名字派出的 subagent（teammate）：像 prism-audit 這類用名字派出的審查員，原本在 [任務] 完全看不到，現在派出就多一行，一輪做完閒著時打勾，收到訊息醒來又回到進行中。workflow 派的 agent 仍然不列。

## 0.8.2

- `/clear` 之後面板恢復得更快：不再把 [SKILL] 的用法整套重新整理一輪（原本每次都要重找、重讀所有 skill 的原文）。用法要更新時照舊按「更新用法」。`/clear` 時還在整理的用法或產生中的教學，按鈕照樣顯示進行中。
- [SKILL] 更順：翻譯說明或整理用法跑完之後，切回 [SKILL] 不再重新分組一次。
- 重繪更省：一頁放不下時版面只排一次、[設定] 不再重讀更新的標示、打開用法頁只重繪一次。
- 其餘是內部整理，畫面與操作都和 0.8.1 一樣。

## 0.8.1

- [任務] 路線圖：實作票開在別的 effort 時，規格書的 `Status:` 寫完成（resolved、done 等）就顯示「已完成」，不再一直停在「待拆票」。
- 畫面重繪更快：一件事最多重繪一次、每頁只讀畫出來的狀態、值沒變就不寫，切分頁與 [任務] 更順。
- [SKILL] 搜尋框暫時拿掉：打字時輸入框會掉焦點，修好再放回來。

## 0.8.0

- [任務] 看得到每個 subagent：主對話派出 subagent 的那一刻就多一行，不管它有沒有寫清單，寫著它在做什麼、狀態（`●` 進行中、`✓` 完成、`✗` 被停掉或出錯）與做了多久；有清單的，任務接在這一行底下並標 `done/total`。結束的整列變暗，按 `c` 連同它的任務一起清掉；滑鼠移上去，說明區看得到它的類型、完整的模型、深度與派工 prompt 的開頭。
- subagent 用的模型或深度跟主對話不同時，行尾標出來，例如「haiku · medium」；跟主對話一樣的不標，一眼看出哪些工作交給了別的模型。面板窄的時候改成縮寫「H·md」。
- 路線圖看得出誰在做哪張票：這個 session 裡交給 subagent 的票，行尾標它的模型與深度（同樣只標跟主對話不同的）；滑鼠移到票上，說明區寫「主對話在做」或「subagent「<描述>」在做」。其餘操作都和以前一樣。

## 0.7.5

- [任務] 路線圖的「已完成 effort」（`d`）與「重新載入路線圖」（`r`）移到下框線，翻到哪一頁都在；之前畫面被自動翻到後面的頁時，這兩個按鈕會不見。
- 看路線圖時不再被拉走：按 `r` 會翻回路線圖那一頁，點開 effort 看票時也一樣，模型更新待辦不會把畫面翻到進行中的任務；切到別的分頁、手動翻頁或收起所有 effort 後恢復自動翻頁。

## 0.7.4

- 內部整理：更新、[SKILL] 的開關與目錄、按鈕寬度的程式重新整理過，畫面與操作都和 0.7.3 一樣。

## 0.7.2

## 0.7.1

- 面板在側邊時，下方的框撐到面板底，說明區貼著下緣；說明區的高度照最長的那一則說明決定，長說明不再被截掉。
- 各分頁的操作（[SKILL] 的開關與更新用法、[基本] 的編輯與重新載入、[任務] 的清除已完成）都移到下框線的左端，翻頁鍵在右端，每個分頁都在同一個位置。
- [SKILL] 比較好找焦點：skill 名稱後面的 `?` 平常藏著，滑鼠停在名稱上才出現；組名加粗、個數與分類的統計變暗；排成幾欄時，欄與欄之間多一條暗色直線。

## 0.7.0

- [SKILL] 可以把組歸進自己定義的分類（例如「專案」「介面」「工具」）：在 [設定] 按「編輯 SKILL 覆寫」，在 `categories` 裡寫。寫了之後搜尋列下方多一排分類分頁籤，一次看一個分類；沒寫的話畫面和以前一樣。
- [SKILL] 按 `o` 進開關模式，可以把單一 skill 從模型看到的 skill 清單拿掉：模型當下就叫不到它，你仍然可以自己打 `/名稱`，清單的 token 從下一個 session 起省下來。也可以一次關掉整組或整個分類，分類、組、skill 都標出佔多少 token，看得出關哪個最划算。關掉的 skill 與組在平常模式變暗。開關只影響目前這個專案，存在專案的 `.claude/settings.local.json`，和 Claude Code 的 `/skills` 選單共用同一份設定。plugin 的 skill 不能單獨關，plugin 組的開關改成在這個專案停用整個 plugin（連它的指令、hook、agent 一起停），按下去 cockpit 會代你跑 `/reload-plugins`。

## 0.6.1

- 修正：剛裝好的 cockpit 按「立即更新」或自動下載新版時會失敗（訊息是 not installed）。現在會自己補上，不必你處理。

## 0.6.0

- 開場會自己看有沒有新版：有的話跳一次提示，並在 [設定] 版本號那一列與分頁列的「設定」留著記號，直到你換上為止。
- 更新前看得到這一版改了什麼：「檢查版本」的詢問會列出來，[設定] 最下面也多了「更新紀錄」可以隨時打開。
- 發布的版本被退回時，你的 cockpit 會自己跟著退回（「自動更新」關著也一樣），並明白告訴你這是退回。

## 0.5.3

- [設定] 最下面的版本號後面多了「檢查版本」：按一下就知道有沒有發布不一樣的版本，要的話當下換上，不必重開 Claude Code。
- [設定] 多了「自動更新」（預設關）：打開後每次開場會自己看一次，有不一樣的版本就先下載，下次開啟時換上。
- 換了版本之後，開場會跳一則提示告訴你現在是哪一版。
